PLECS — the control in the C-Script block, generated by MaiSim.
The same C as in the SIL, as a single text (the control, the modules and MaiSim's headers together). Set up the block (Setup) like this:
  - Number of inputs: {{N_M}} (a Mux, in this order: {{ORDEM_M}})
  - Number of outputs: {{N_U}} (a Demux, in this order: {{ORDEM_U}})
  - Sample time: {{TS}}
  - Direct feedthrough: on
and copy each section below into the one of the same name (Code).

static long long maisim_estado[1 << 12];

{ int k; for (k = 0; k < MAISIM_N_P; k++) maisim_p[k] = maisim_p_iniciais[k]; for (k = 0; k < MAISIM_N_U; k++) maisim_ultima[k] = 0; }
maisim_iniciar(maisim_p, maisim_estado);
