PLECS — o controle no bloco C-Script, gerado pelo MaiSim.
O mesmo C do SIL, num texto só (o controle, os módulos e os .h do MaiSim juntos). Configure o bloco (Setup) assim:
  - Number of inputs: {{N_M}} (um Mux, nesta ordem: {{ORDEM_M}})
  - Number of outputs: {{N_U}} (um Demux, nesta ordem: {{ORDEM_U}})
  - Sample time: {{TS}}
  - Direct feedthrough: on
e copie cada seção abaixo para a de mesmo nome (Code).

==================== Code declarations ====================
{{CODIGO}}
static maisim_real maisim_m[MAISIM_N_M], maisim_p[MAISIM_N_P], maisim_u[MAISIM_N_U], maisim_ultima[MAISIM_N_U];
static long long maisim_estado[1 << 12];
static int maisim_cabe;   /* maisim_tamanho_estado() <= sizeof maisim_estado */

{ int k; for (k = 0; k < MAISIM_N_P; k++) maisim_p[k] = maisim_p_iniciais[k]; for (k = 0; k < MAISIM_N_U; k++) maisim_ultima[k] = 0; }
maisim_cabe = maisim_tamanho_estado() <= sizeof maisim_estado;
if (maisim_cabe) maisim_iniciar(maisim_p, maisim_estado);
