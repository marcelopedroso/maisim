## What each folder has (one controller = one firmware or one block)

- `*.c`, `*.h`: the control (the same as in MaiSim) and its modules.
- `maisim_controle.h`: the contract (`maisim_iniciar`, `maisim_passo`, `maisim_scope`, `maisim_envia`, `maisim_recebeu`).
- `maisim_sinais.h`: the indices of this controller's measurements (`M_…`), parameters (`P_…`) and actuations (`U_…`).
- `maisim_parametros.h`: Ts and the panel's parameter values (the starting `p[]`).
- `maisim_alvo.c`: what the target gives the control (scope and messages): fill in the messages if there is more than one controller.
- `alvos/`: what belongs to the target (see below).
- `teste/replay.c`: the same control on the PC from a CSV of measurements, to compare with the MaiSim run before the hardware.
