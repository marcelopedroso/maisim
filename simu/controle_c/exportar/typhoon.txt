Typhoon HIL — o controle no bloco C function (Schematic Editor), gerado pelo MaiSim.
O mesmo C do SIL, num texto só (o controle, os módulos e os .h do MaiSim juntos). Configure o bloco assim:
  - Execution rate: {{TS}} s
  - Entradas (real): {{ENTRADAS}}
  - Saídas (real): {{SAIDAS}}
