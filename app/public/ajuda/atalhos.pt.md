# Atalhos de teclado

Os principais atalhos de teclado do MaiSim para agilizar a navegação, desenho de esquemáticos e controle da simulação.

## Teclas globais e ajuda

| Tecla | Função |
|---|---|
| **F1** | Abre e fecha o painel lateral de ajuda com o tópico da tela atual |
| **Esc** | Fecha o painel de ajuda, menus flutuantes, seleções ou diálogos modais |

## Editor de circuitos (Simu)

| Tecla | Função |
|---|---|
| **Ctrl+Enter** | Inicia a simulação do circuito aberto |
| **Espaço** | Pausa ou continua a execução da simulação |
| **Ctrl+S** | Salva o circuito atual e os arquivos de controle |
| **Ctrl+Z** | Desfaz a última ação no esquemático elétrico |
| **W** | Ativa ou desativa a ferramenta de desenho de fios |
| **R** | Gira o componente selecionado no sentido horário |
| **Delete** / **Backspace** | Exclui o componente, grupo ou fio selecionado |
| **Ctrl+C** | Copia os componentes selecionados para a área de transferência |
| **Ctrl+X** | Recorta os componentes selecionados |
| **Ctrl+V** | Cola os componentes na posição apontada pelo mouse |
| **0** | Enquadra e ajusta o zoom para visualizar a folha inteira |

## Osciloscópio (Scope)

| Tecla | Função |
|---|---|
| **Roda do mouse** | Amplia ou reduz o zoom temporal na posição do cursor |
| **Duplo clique** | Restaura o zoom padrão do eixo temporal |
| **Arrastar (botão esquerdo)** | Desloca a janela de tempo horizontalmente |
