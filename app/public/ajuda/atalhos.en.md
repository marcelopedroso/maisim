# Keyboard shortcuts

Key shortcuts throughout MaiSim to speed up schematic capture, waveform inspection, and simulation control.

## Global shortcuts and help

| Shortcut | Action |
|---|---|
| **F1** | Opens and closes the slide-over help drawer for the current screen |
| **Esc** | Closes the help panel, context menus, selections, or open dialogs |

## Circuit editor (Simu)

| Shortcut | Action |
|---|---|
| **Ctrl+Enter** | Starts simulation of the active circuit |
| **Space** | Pauses or resumes simulation execution |
| **Ctrl+S** | Saves the active circuit and Python control code |
| **Ctrl+Z** | Undoes the last schematic editing action |
| **W** | Toggles interactive wire connection drawing mode |
| **R** | Rotates the selected component clockwise |
| **Delete** / **Backspace** | Deletes selected component, group, or wire segment |
| **Ctrl+C** | Copies selected components to clipboard |
| **Ctrl+X** | Cuts selected components to clipboard |
| **Ctrl+V** | Pastes copied components at mouse cursor location |
| **0** | Fits schematic sheet to zoom viewport |

## Oscilloscope (Scope)

| Shortcut | Action |
|---|---|
| **Mouse wheel** | Zooms in or out horizontally around cursor position |
| **Double click** | Resets horizontal time scale to initial zoom |
| **Left drag** | Pans time window horizontally across samples |
